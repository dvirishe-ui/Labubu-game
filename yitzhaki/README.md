# המשחקייה על הגג

משחקי מסיבה בעברית (RTL, מותאם לטלפון) בהשראת פינות המשחק בפודקאסט. אתר מעריצים לא רשמי — אין קשר או אישור מטעם היוצרים.

> ⚠️ תיקיית `data/` ומצב העורך מכילים את כל השאלות והתשובות. מי שמתכנן לשחק — לא לפתוח. מצב העורך נעול בסיסמה.

## הרצה

```bash
cd yitzhaki
npm install
npm run build      # בונה את מאגר הנתונים + האתר לתיקיית dist/
npm start          # שרת על http://localhost:8787 (חדר מסיבה + שמירת פרופילים וטבלאות)
```

- פיתוח: `npm run dev` (חדר מסיבה ושמירה בשרת עובדים בפיתוח רק אם `npm start` רץ במקביל).
- בדיקות: `npm test`.
- עמוד יחיד לאירוח: `VITE_SHARE_URL=<כתובת העמוד> node scripts/build-single.mjs out.html`.
- הנתונים של השרת נשמרים ב־`server/data/store.json` (או בנתיב שב־`STORE_FILE`).

## מה יש

**משחק לבד** — "המסלול של יצחקי": 3 לבבות, שלבים, אתגר מיוחד כל 5 סיבובים (שלוש אפשרויות), בוס כל 10, כוחות שמגיעים רק מאיסטר אגים (ראו למטה), שיאים וריצה שנשמרת. "דילמות נגד כולם": בוחרים ומנחשים את הרוב מול הצבעות אמיתיות.

**אתגר יומי** — אותן 10 שאלות לכולם ביום, ניסיון מדורג אחד (רענון ממשיך מאותה שאלה), טבלאות יומית ושבועית.

**תנצח אותי** — אתגר חבר עם קוד או קישור; שניכם מקבלים אותן שאלות, גם בזמנים שונים.

**נגד כולם** — אחרי כל תשובה רואים כמה שחקנים אמיתיים צדקו. נספרת רק התשובה הראשונה של כל שחקן, ומוצג רק כשיש לפחות 3 שחקנים אחרים.

**משחק עם חברים** — טלפון אחד (2–10 שחקנים) או קבוצות (2–4), כל הפינות לפי קטגוריות (ניחוש / החלטות / מסיבה). בדילמות: הרוב קובע, הכבשה השחורה, נחש את הרוב, מי בחר מה.

**משחקי מסיבה חדשים** (מכניקות חדשות על תוכן מהפודקאסט): המתחזה של יצחקי, מי כתב את זה?, הבלוף הגדול, מי הכי מכיר את החבורה?, הקרב על הגג, מה יצחקי היה ממציא? (תוכן שחקנים מסומן ככזה).

**ערב על הגג** — סשן מעורב של 10/20/30/60 דקות, ניקוד רציף וסיכום: מנצח, הכי הרבה תשובות נכונות, בלופים מוצלחים, דעות לא פופולריות, קאמבק, מטבעות והישגים.

**מטבעות הגג** — מרוויחים רק במשחק (40 על סיום משחק, 60 על ניצחון, 100 על אתגר יומי, 100 על משחק מושלם, 500 על האתגר השבועי, 100–500 על הישגים). תקרות יומיות, פרס פעם אחת לכל משחק, ומינימום 5 סבבים ודקה כדי שאי אפשר יהיה "לחלוב" מטבעות. אין רכישות בכסף ואין קופסאות הפתעה.

**חנות הגג והאוסף שלי** — בדיוק שמונה דמויות (אסף יצחקי, יונתן ברק, חן מזרחי, מתן פרץ, נועם אונגר, דור יתח, טל ראשון, צח רוקח), לכל אחת סקין קלאסי, מיוחד, אגדי וזהב, ולאסף גם "מלך הגג". הסקין הקלאסי מגיע עם הדמות; כל סקין אחר עולה מחיר הדמות ועוד תוספת לפי הדרגה (מיוחד +2,500–4,000, אגדי +7,500–12,000, זהב +25,000), ו"מלך הגג" עולה 60,000. לכל סקין מחיר אחר. סקינים קוסמטיים בלבד. הראשים מאוירים בסגנון משחק (`src/components/heads.tsx`) לפי התמונות ב־`assets/cast` — שיער, זקן, גוון עור וצורת פנים — בלי פיקסלים מהתמונות עצמן.

**איסטר אגים** — אין יותר כוחות בחינם. בחנות קונים כל איסטר אג לבד, לא משנה איזו דמות יש לך, וכל אחד פותח כוח במסלול של יצחקי: צ׳יפים (דור יתח) — 50/50 בשאלת שלוש אפשרויות או כפול או כלום בשאלה רגילה; מקטורת ופייסל (יונתן ברק) — דילוג; משקולות (אסף יצחקי) — לב נוסף; טלפון (מתן פרץ) — התשובה הנכונה; שקית קוק (טל ראשון) — עוד 10 שניות. "זוג מנצח" לא נמכר: נפתח למי שיש את צח רוקח ואת נועם אונגר, ושניהם משחקים ביחד — פעם בשלב טעות אחת לא עולה לב. כל ריצה מתחילה עם כוח אחד מכל איסטר אג, ועוד אחד במתנה בכל שלב. ההגדרות ב־`src/lib/eggs.ts`.

**דמות סודית** — לא מופיעה בחנות ואי אפשר לקנות אותה. מקבלים אותה רק בסיום המשחקון הנסתר "מכונת הזמן" (מהיום עד 2028 — משם הוא מגיע; שלוש תקופות).

**התקדמות** — רמות ו־XP, 16 הישגים, אתגר שבועי (לא חובה), שיאים אישיים, דמות אהובה.

**חדר מסיבה** (בשרת בלבד) — חדר פרטי עם קוד או QR, כל אחד מהטלפון שלו עם הדמות שלו, חדר המתנה, התחברות מחדש. השרת בוחר את השאלות, שומר את התשובות בסוד עד החשיפה, מריץ את הטיימר ומחשב את הניקוד.

**פתקים על הגג** — משחק בונוס מקורי (לא פינה מהפודקאסט).

**מצב עורך** (בסיסמה) — ייבוא JSON/CSV, יצירת שאלות מתמליל, עריכה, אישור, השבתה, זיהוי כפילויות, חוקים, ספירות.

## איפה נשמרת ההתקדמות

- בתוך Claude (עמוד ה־Artifact): במסד הנתונים של העמוד — פרופיל פרטי לכל משתמש, ומסמכים משותפים לטבלאות ולסטטיסטיקות.
- בשרת (`npm start`): בקובץ JSON בשרת.
- אחרת: רק בדפדפן הזה.

מכיוון שהלוגיקה רצה בדפדפן, מי שמתעקש יכול לערוך את הנתונים של עצמו; הבדיקות (פרס פעם אחת, תקרות, ניסיון יומי אחד) מונעות ניצול רגיל אבל אינן מערכת אבטחה.

## הנתונים

- `data/extraction/*.json` — חילוץ ידני, שורה-שורה, מהתמלילים שסופקו (מקור, טווח שורות, חותמות זמן, ראיה גולמית, רמת ביטחון).
- `scripts/build-data.mjs` מייצר מהם את `data/games.json`, `data/questions.json`, `data/source_segments.json`, `data/needs_review.json`, `data/coverage.json`, ואת חבילת המשחק `src/generated/`.
- שאלה נכנסת למשחק רק אם יש חשיפה ברורה בפודקאסט וביטחון בינוני/גבוה. ״התשובה הנכונה״ היא מה שנחשף בפודקאסט (`answer_basis: podcast_reveal`).
- בחבילת האתר התשובות מוצפנות קלות כדי שלא ייראו לפני ההצבעה.
