# המשחקייה על הגג

משחקי מסיבה בעברית (RTL, מותאם לטלפון) בהשראת פינות המשחק בפודקאסט. אתר מעריצים לא רשמי — אין קשר או אישור מטעם היוצרים.

> ⚠️ תיקיית `data/` ומצב העורך מכילים את כל השאלות והתשובות. מי שמתכנן לשחק — לא לפתוח.

## הרצה

```bash
cd yitzhaki
npm install
npm run build      # בונה את מאגר הנתונים + האתר לתיקיית dist/
npm start          # שרת על http://localhost:8787 (כולל "חדר מסיבה")
```

- פיתוח: `npm run dev` (חדר מסיבה עובד בפיתוח רק אם `npm start` רץ במקביל).
- בדיקות: `npm test`.
- אירוח סטטי: אפשר להעלות את `dist/` לכל אחסון סטטי. בלי השרת, כפתור "חדר מסיבה" פשוט לא מוצג.

## מה יש

- **מנועי משחק:** אמיתי/מומצא, דילמות (בלי תשובה נכונה, התפלגות הצבעות, ניחוש הרוב אופציונלי), פאק מארי קיל (18+), תשובות יצירתיות עם הצבעה אנונימית, הכיסא החם (בידור בלבד — לא גלאי שקר).
- **מצבים:** טלפון אחד (2–10 שחקנים, הצבעה גלויה או סודית עם מסך העברה), קבוצות (2–4), משחק מהיר (5/10/15), מרתון (בלי חזרות), חדר מסיבה (WebSocket, כל אחד מהטלפון שלו).
- **פתקים על הגג** — משחק בונוס מקורי (לא פינה מהפודקאסט): תיאור, מילה אחת, פנטומימה.
- **מצב 18+** עם אישור גיל; תוכן בוטה מוסתר כברירת מחדל.
- **מצב עורך:** ייבוא JSON/CSV, יצירת שאלות מתמליל מודבק לפי טווח שורות, עריכה, אישור ידני של שאלות לא ודאיות, השבתה, זיהוי כפילויות, חוקים מותאמים, ספירות לכל משחק. השינויים נשמרים במכשיר וניתנים לייצוא.
- שמירה מקומית: שחקנים, משחק פעיל (אפשר להמשיך אחרי רענון), היסטוריית שאלות שנראו.

## הנתונים

- `data/extraction/*.json` — חילוץ ידני, שורה-שורה, מהתמלילים שסופקו (מקור, טווח שורות, חותמות זמן, ראיה גולמית, רמת ביטחון).
- `scripts/build-data.mjs` מייצר מהם את `data/games.json`, `data/questions.json`, `data/source_segments.json`, `data/needs_review.json`, `data/coverage.json`, ואת חבילת המשחק `src/generated/`.
- שאלה נכנסת למשחק רק אם יש חשיפה ברורה בפודקאסט וביטחון בינוני/גבוה. ״התשובה הנכונה״ היא מה שנחשף בפודקאסט (`answer_basis: podcast_reveal`), לא בדיקת עובדות.
- בחבילת האתר התשובות והחשיפות מוצפנות קלות כדי שלא ייראו בטעות לפני ההצבעה.
